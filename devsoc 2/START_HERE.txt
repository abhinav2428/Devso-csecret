## ✅ How It Works

```
You Type a Question
        ↓
Browser sends HTTP request
        ↓
Flask processes request
        ↓
Calls bot.py functions
        ↓
Bot Planning Agent (decompose)
        ↓
Bot Execution Agent (multiple paths)
        ↓
MoE Verification (3 experts agree)
        ↓
Synthesis Agent (final answer)
        ↓
Response sent back as JSON
        ↓
Frontend displays with ✓ Verified badge
```


### "FAISS not found"
