## 📊 Integration Points

1. **Bot Integration**
   - Flask imports `generate_response_got` from bot.py
   - Calls bot function directly
   - Returns response as JSON

2. **Database Integration**
   - Vector DB (FAISS) - used by bot
   - Knowledge Graph (NetworkX) - used by bot
   - Both accessed through bot.py unchanged

3. **API Integration**
   - Frontend sends HTTP POST to `/api/chat`
   - Backend processes and calls bot
   - Returns JSON response
   - Frontend displays in chat UI

## 🔄 Data Flow

```
User Types Message
    ↓
Frontend JavaScript (script.js)
    ↓
HTTP POST /api/chat {message}
    ↓
Flask Backend (app.py)
    ↓
Calls bot.generate_response_got(message)
    ↓
Bot Core (bot.py)
    ├─ Planning Agent
    ├─ Execution Agent (multiple paths)
    ├─ MoE Verification (3 experts)
    └─ Synthesis Agent
    ↓
Returns string response
    ↓
Flask formats JSON
    ↓
HTTP 200 {response, success, timestamp}
    ↓
Frontend JavaScript receives
    ↓
Displays in chat interface
```

## 🚀 How to Use

### Quick Start
```bash
# Install dependencies
pip install -r requirements.txt

# Run the bot (choose one)
python run.py          # Recommended
# or
python run.bat         # Windows
# or
python app.py          # Manual

# Open browser
# http://127.0.0.1:5000
```

### For Development
```bash
# Keep these running:
1. Terminal: python run.py
2. Browser: http://127.0.0.1:5000
3. Optional: DevTools (F12) for debugging
```

### For Production
```bash
# Using Gunicorn
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```
